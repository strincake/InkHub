# 桌面便签与时钟

在独立“便签工作室”主页中编辑标题与多条便签；画面可以显示电脑本地时间。宿主设置表单提供画面颜色、更新间隔和时钟开关。

上下键切换便签，确认键切换明暗；插件中心还提供“换一条便签”和“重置计数”动作。它与其他插件共用宿主的优先级、展示时间和设备连接规则。

在项目根目录执行 `./pack-plugins.ps1`，然后在插件中心安装 `dist/plugins/desk-note.screen-plugin.zip` 并启用。本目录也演示持久状态、按键、定时、宿主表单与插件主页的组合，详见[开发指南](../../docs/guides/plugin-development.md)。
