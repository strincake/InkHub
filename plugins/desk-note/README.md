# 便签

在独立主页中管理多张便签：左侧列表可滚动并切换便签，中间编辑正文，右侧以 400×300 画面实时预览。点击“新建”添加便签，在编辑框内点击“删除当前便签”删除。切换便签保留当前草稿，点击“应用到设备”后保存全部便签并显示当前选中的一张。

每张便签独立设置标题、标题开关和正文字号（12～64 px）。关闭标题时，列表使用正文前 12 个字符作为名称；空白便签显示“空白便签”。关闭的标题仍会保留，再次开启可继续使用。正文中的回车保留为换行，长行根据实际字宽自动折行，超出画面时在末尾显示省略号。设备画面不显示日期、时间和序号。

上下键切换便签，确认键切换明暗；插件中心还提供“换一条便签”和“回到第一张”动作。宿主设置表单提供画面颜色与更新间隔。显示优先级、展示时间和设备连接规则沿用宿主设置。

旧版本的逐行便签在首次打开新版主页时按原有规则读成多张便签；首次应用后以结构化列表保存，后续正文换行不再拆成多张便签。删除全部便签后，设备显示空白画面，可随时新建。

在项目根目录执行 `./pack-plugins.ps1`，输出 `dist/plugins/desk-note.screen-plugin.zip`。Release 构建会嵌入新版源码包；已有同 ID 的安装包不会自动覆盖。开发接口见[开发指南](../../docs/guides/plugin-development.md)。
