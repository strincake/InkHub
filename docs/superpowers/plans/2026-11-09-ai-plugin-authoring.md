# AI 插件编写与首页调整

用户确认：插件页填写需求，通过本地 MCP 或 API 生成可导入插件；提供外部 AI 可用的 Skill。已有插件更新改动一并提交。

## 实现

1. `web/index.html`、`web/app.js`、`web/style.css`：移除模式选择，队列放在预览下方；断开后回到模拟模式；favicon 复用程序 ICO。
2. `skills/inkhub-plugin/SKILL.md`：封装开发流程，附完整开发指南；宿主内嵌文档以保证安装版可下载。
3. `python/ai_plugin.py`、`src/ai.rs`：宿主通过标准输入调用 Python，API 支持 Chat Completions 与 Anthropic Messages；本地 MCP 支持 stdio 和 Streamable HTTP，先发现工具再由用户指定工具及参数模板。生成只返回源码和 ZIP，不执行或安装。校验路径、大小、清单与 Python 语法。
4. `web/ai.js`：独立对话框，预设服务商 endpoint、自定义模型、本机连接设置（不持久化密钥）；结果可查看源码、下载、进入既有安装预览流程。
5. 验证：Python 单元测试覆盖生成校验、API/MCP 模拟；Rust 编译测试；浏览器验证首页布局、生成及安装、错误恢复和原有插件更新流程。使用隔离配置，不更改用户运行实例。

## 边界

- MCP 本身不提供模型；需连接提供生成工具的本地服务器。UI 展示实际工具 schema，参数模板中的需求与说明占位符由宿主替换。
- 不发送已有插件、个人配置或密钥到生成提示词；不自动执行生成代码。
- 网络失败、认证错误、无生成工具、非法路径或不合规结果必须明确报错并允许重试。
- 保留原有插件更新逻辑及安装确认流程。
