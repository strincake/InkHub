# 便签更新 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan inline. User authorized direct implementation without further preview confirmation.

**Goal:** 将内置便签更新为独立列表、编辑和实时预览的多便签工具。

**Architecture:** 保留 desk-note 插件 ID 和宿主消息协议。JSON 设置 document 存储逐张便签，旧 title/notes 仅用于兼容读取；每张包含 id/title/text/font_size/show_title。active_note 保存应用到设备的选择，设备按键保留翻阅能力。

**Tech Stack:** Python/Pillow, HTML/CSS/JavaScript, unittest, browser automation.

**Spec:** 本次对话中批准的第二版预览及最新修订：删除按钮置于编辑框内，删除画面无页脚的说明文字，直接实施。

## Global Constraints

- 名称与导航统一为“便签”；左侧独立竖向滚动列表。
- 每张独立字号、标题开关；关闭标题以正文前几个字命名，空白显示“空白便签”。
- 正文保留换行；设备画面移除序号、日期、时间，关闭标题时正文上移。
- 右侧实时预览草稿；显式应用保存并更新设备。切换保留未应用草稿。
- 删除按钮在编辑框内。不修改用户现有的不相关改动，不提交或推送。

## Review Focus

- 旧字符串仍按旧规则迁移成多张便签，只对旧数据执行一次拆行。
- 空列表和空白正文不能崩溃；删除当前张后选择邻近张，允许新建恢复。
- 按键翻阅与主页应用选择协调；普通刷新不能跳回旧选择。
- 长行、中英文、显式空行、不同字号不越出画面。
- 保存失败保留草稿；宿主上下文刷新不能覆盖正在编辑的内容。
