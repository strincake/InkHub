# 数据与版本管理边界

## 应纳入版本管理

- Rust、Python、网页源码与测试源码。
- `Cargo.toml`、根 `Cargo.lock`、`requirements.txt`。
- 三个随附插件的源码均位于 `plugins/`；宿主 Python 文件与插件 API 位于 `python/`。
- `clients/`、固定的 vendor SDK 源码、来源记录和已有许可证。
- 构建、启动、打包脚本及现行文档。

## 不应提交

| 内容 | 原因 / 位置 |
| --- | --- |
| `settings.json` 及其备份 | 可能保存设备地址、HTTP 接入密钥和本机设置 |
| `settings.plugins/` | 已安装包、插件配置、私有状态、相册路径、收件文件与运行目录 |
| `target/`、`node_modules/`、Python 缓存 / 虚拟环境 | 可重新生成的依赖与构建产物 |
| `dist/`、`artifacts/` | 可重新生成的插件包、截图、测试结果、日志和临时数据 |
| 浏览器临时用户目录、集成测试临时目录 | 浏览器状态与合成测试数据 |
| `.env*`、凭据、本机会话和个人图片 | 本机数据；不属于源代码 |

本次迁移通过白名单复制源码，未复制以上旧数据；原文件仍留在原目录。`.gitignore` 用于今后的 Git 忽略，不会删除本机文件。

默认配置路径对应的插件目录均已忽略。使用自定义 `--config` 路径时，应放在仓库外，或自行添加精确忽略规则。提交前仍需查看文件清单与差异，避免把自定义命名的配置作为源码加入。

## 本机运行数据

启动脚本使用项目根目录的 `settings.json`；宿主生成 `settings.plugins/packages`、`data`、`runs` 等子目录。安装并启用工作搭子后，它按用户配置读取本机 Codex 会话元数据，这些会话不属于本仓库。

卸载插件会删除它的本机设置和私有数据。插件 ZIP 从源码目录打包，不能从已安装状态目录随意打包分享。
